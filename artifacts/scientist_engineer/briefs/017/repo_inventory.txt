# Public Reproduction

Run:

```bash
python reproduce.py
```

The harness creates deterministic WCS geometries and evaluates the real
Gammapy `JFactory` workflow with NFW profiles. It prints a JSON report with
angular coverage, output shape, and whether each calculation completed with
finite values. The wide-field cases expose the scientific inconsistency; the
report does not identify a source line or reveal the intended code change.

The report has three deliberately distinct result states:

- `post_fix_success`: the calculation completed and returned finite values.
- `pre_fix_expected_failure`: the scientific calculation raised an exception
  or returned a non-finite result. This is the expected state for the pinned
  historical source; after an Agent edit it indicates a regression.
- `runner_failure`: the subprocess, import path, timeout, or JSON protocol
  failed before a scientific result was available.

The script exits with code `0` only when every case is
`post_fix_success`. A pre-fix run therefore exits nonzero while still emitting
a structured scientific failure report; a post-fix run exits zero.

The task declares a Python 3.12 dependency runtime with the pinned scientific
packages. The candidate source remains in the mounted task workspace and is
prepended to `PYTHONPATH`; it is not installed into the cached dependency
image. The source snapshot contains a minimal source-tree version fallback so
imports do not depend on an editable package install. No network or external
Gammapy data registry is needed.

# Offline Scientific Note: Dark-Matter Line-of-Sight Maps

This note gives the background needed to reason about the task without network
access. It is a compact rendering of the line-of-sight geometry used in
dark-matter indirect-detection calculations.

## What the map represents

An observer looks through a dark-matter halo. For a direction on the sky, the
spatial factor in the predicted gamma-ray signal is an integral along that ray:

```text
dJ_ann / dOmega = integral rho(r(l))^2 dl
dJ_dec / dOmega = integral rho(r(l)) dl
```

The first expression is used for annihilation and the second for decay. The
software supports both modes. The density `rho` is supplied by a profile such
as NFW, Einasto, or Burkert, and the result carries physical units.

Let `D` be the observer-to-halo-centre distance and let `theta` be the angular
separation between the ray and the centre direction. The ray's perpendicular
distance from the halo centre is the impact parameter:

```text
b = D sin(theta)
```

This is a geometric distance to a line. It is not the distance obtained by
extending a right triangle's opposite side to the observer distance.

## Radial form of the integral

Using the distance `r` from the halo centre, one line-of-sight branch has the
Jacobian

```text
dl = r / sqrt(r^2 - b^2) dr.
```

The closest point `r=b` makes the denominator appear singular. The singularity
is integrable, but evaluating the expression directly at the endpoint is
numerically fragile. A stable change of variable is:

```text
r = b cosh(t)
```

which maps the closest approach to `t=0` and removes the square-root endpoint
problem from the numerical quadrature. The two sides of the ray before the
observer-to-centre distance contribute symmetrically; the remaining far branch
continues beyond that distance. The exact truncation used by the source is part
of the existing model and should be preserved.

## Branch bookkeeping and limiting cases

For one fixed sightline, `b` is a property of the ray and must remain the same
in every radial branch. The lower radial bound is a separate quantity: a branch
may start at `r = D` while its Jacobian still contains the same `b = D sin(theta)`.
Confusing these two roles changes the physical path length even when the code
returns a finite array.

The calculation follows the forward ray from the observer. For
`theta <= 90 degrees`, the ray passes the centre-side closest approach before
continuing outward, so the `[b, D]` contribution is counted twice and the
`[D, 4D]` contribution is counted once. For `theta > 90 degrees`, the observer
itself is already the closest point on the forward ray; there is no doubled
`[b, D]` contribution, but the far branch still uses the same impact parameter.

At `b = 0`, the `r = b cosh(t)` substitution is degenerate. A correct limiting
implementation must integrate the original radial interval directly and keep
its requested lower and upper bounds. It must not silently replace the lower
bound with an arbitrary value.

## Units and physical modes

`D`, `b`, `r`, and the profile scale radius are quantities with distance units.
The annihilation result has density-squared times length units, while the decay
result has density times length units. A correct implementation must preserve
these units when the same physical distance is expressed in kpc or pc.

        """Angle for a given radius.

        Parameters

def interpolate_profile_map(flux_map, dnde_scan_axis=None):
    """Interpolate sparse likelihood profile to regular grid.

    Parameters
    ----------
    flux_map : `~gammapy.estimators.FluxMaps`
        Flux map.
    dnde_scan_axis : `~gammapy.maps.MapAxis`
        Map axis providing the dnde values used to compute the profile.
        Default is None and it will be derived from the flux_map.

    Returns
    -------
    scan_map: `~gammapy.estimators.Maps`
        Likelihood profile map.

    """
    stat_scan = _default_scan_map(flux_map, dnde_scan_axis)
    dnde_scan_axis = stat_scan.geom.axes["dnde"]

    mask_valid = ~np.isnan(flux_map.dnde.data)
    dnde_scan_values = flux_map.dnde_scan_values.quantity.to_value(dnde_scan_axis.unit)

    for ij, il, ik in zip(*np.nonzero(mask_valid)):
        spline = InterpolatedUnivariateSpline(
            dnde_scan_values[ij, :, il, ik],
            flux_map.stat_scan.data[ij, :, il, ik],
            k=1,
            ext="raise",
            check_finite=True,
        )
        stat_scan.data[ij, :, il, ik] = spline(dnde_scan_axis.center)
    return stat_scan

def approximate_profile_map(
    flux_map, dnde_scan_axis=None, sqrt_ts_threshold_ul="ignore"
):
    """Likelihood profile approximation.

    This assumes that probabilities distributions for flux points correspond to
    asymmetric gaussians and for upper limits to complementary error functions.
    Use available quantities among dnde, dnde_err, dnde_errp, dnde_errn, dnde_ul and ts.

    Parameters
    ----------
    flux_map : `~gammapy.estimators.FluxMaps`
        Flux map.
    dnde_scan_axis : `~gammapy.maps.MapAxis`
        Map axis providing the dnde values used to compute the profile.
        Default is None and it will be derived from the flux_map.
    sqrt_ts_threshold_ul : int
        Threshold value in sqrt(TS) for upper limits.
        Default is `ignore` and no threshold is applied.
        Setting to `None` will use the one of `flux_map`.

    Returns
    -------
    scan_map: `~gammapy.estimators.Maps`
        Likelihood profile map.
    """
    stat_approx = _default_scan_map(flux_map, dnde_scan_axis)
    dnde_coord = stat_approx.geom.get_coord()["dnde"].value
