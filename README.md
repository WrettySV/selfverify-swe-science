# Cross-Candidate Verification for Scientific Software Repair

- **A — own-test refinement:** test each proposed repair with its own tests and allow a revision when they expose an error.
- **B — cross-selection:** test three proposed repairs with one another's tests and return the repair with the strongest support, excluding its own tests from its score.

Inference uses **Qwen3.8-27B served locally through vLLM**; repository execution and testing use Docker containers.

## Results

| Method | Result |
|---|---|
| Ordinary baseline | 10/27 correct answers; mean pass@1 **37.04%** |
| A: own-test refinement | 12/27 correct answers; mean pass@1 **44.44%** |
| Random choice among B's three repairs | **44.44%** mean selection success |
| B: cross-selection | **50.00%** mean selection success |

B improves selection by **5.56 percentage points** over random choice of the same repairs. Its score averages over equally scored choices: on task 007, two repairs tie and one is correct, contributing 50% for that task. Baseline and A/B use different starting repairs and unmatched total budgets, so their difference is descriptive rather than an equal-cost comparison. Per-attempt tables are regenerated by `scripts/run_study.py`.

## Reproduce the tables

From the repository root, using Python 3.12 or later:

```bash
python3 scripts/run_study.py --out work/study-results
```

This verifies the supplied data and writes Markdown tables, CSV files and JSON metrics. It requires no model or Docker.

## Run new verification

Requires Linux, Docker, the SWE-bench Science release and a running vLLM endpoint. Create `model.env` from `profiles/vllm-qwen38.env.example` and set its `CODEX_BASE_URL` to the address reachable from Docker.

```bash
python3 scripts/run_study.py --new-tests \
  --science-root /path/to/SWE-bench-Science/huggingface \
  --env-file /path/to/model.env \
  --out work/study-new-tests
```

This generates new tests, executes them, allows own-test refinement and computes cross-selection results. It starts from the supplied repairs, as in the reported experiment. Use `--task 007` to run one task; the output directory must be new.
